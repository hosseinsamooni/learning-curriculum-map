# Learning Curriculum Map

**A wayfinding project to design a comprehensive learning path from programming fundamentals to AI systems mastery.**

## Destination

A unified learning curriculum that combines:
- **DevFoundations-Journey**: Language-agnostic system thinking, architecture, and product development
- **ai-engineering-from-scratch**: 528 lessons from math foundations through production AI systems

**For**: Someone starting from "I can't read code" and reaching "I design AI systems, understand internals, and train models"

## Status

🗺️ **Charting phase**: Mapping the terrain, resolving key design decisions

The wayfinding map lives in [GitHub Issues](https://github.com/hosseinsamooni/learning-curriculum-map/issues?q=is%3Aissue+label%3Awayfinder%3Amap).

## Background

This project uses the [wayfinding methodology](https://github.com/hosseinsamooni/.hermes/profiles/developering/.agents/skills/wayfinder/SKILL.md) to plan large, foggy work. Each ticket resolves one decision; the map is done when the route to the destination is clear.

### What exists today

**DevFoundations-Journey** ([repo](https://github.com/hosseinsamooni/DevFoundations-Journey))
- Custom curriculum teaching system architecture, APIs, databases, product thinking
- Language-agnostic, concepts-first approach
- Status: 1 lesson created, structured for 6 phases

**ai-engineering-from-scratch** ([repo](https://github.com/rohitg00/ai-engineering-from-scratch))
- 528 lessons across 20 phases
- Math → ML → Deep Learning → LLMs → Agents → Production
- Multiple languages: Python, TypeScript, Rust, Julia
- Website, agent skills, project-based learning

### The challenge

How do we merge these into a coherent learning path that:
1. Starts from absolute zero (can't read code)
2. Teaches both system thinking AND AI internals
3. Sequences optimally (programming first? math first? interleaved?)
4. Avoids redundancy where they overlap
5. Provides clear milestones and prerequisites
